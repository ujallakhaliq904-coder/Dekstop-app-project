# Smart Expense Tracker with Analytics

A professional, final-year level desktop application built using Python and Tkinter for managing personal finances.

## Overview
The Smart Expense Tracker allows users to monitor their income, set budgets, and visualize their spending habits. Data is stored securely offline using SQLite.

## Features
- **User Authentication**: Secure registration and login system.
- **CRUD Operations**: Add, Edit, Delete, and View expenses.
- **Categorization**: Manage dynamic spending categories.
- **Budgeting**: Set and track monthly budgets.
- **Analytics Dashboard**: Matplotlib integration for Pie and Bar charts.
- **Themes**: Switch between Light and Dark mode.
- **Data Export**: Export expenses to CSV.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/username/smart-expense-tracker.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python main.py
   ```

## Usage
1. Register a new account.
2. Log in and navigate to the Dashboard.
3. Add expenses and set a budget for the current month.
4. Go to the Analytics tab to view visual reports.
5. Export data to CSV from the Dashboard toolbar.
