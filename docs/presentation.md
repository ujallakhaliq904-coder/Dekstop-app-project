# Smart Expense Tracker - Presentation Slides

## Slide 1: Title
- **Project**: Smart Expense Tracker with Analytics
- **Author**: [Student Name]
- **Course**: Software Construction and Development

## Slide 2: Introduction
- What is it? A desktop application to manage personal finances.
- Built with Python, Tkinter, and SQLite.
- Fully offline and secure.

## Slide 3: Problem Statement
- Hard to track daily expenses manually.
- Existing tools are often bloated or require internet.
- Lack of visual representation of spending habits.

## Slide 4: Objectives
- Develop an intuitive GUI for quick data entry.
- Provide data persistence using SQLite.
- Implement data visualization for better insights.

## Slide 5: Technologies Used
- **Python**: Core logic.
- **Tkinter**: Graphical User Interface.
- **SQLite**: Database management.
- **Matplotlib**: Generating charts and graphs.

## Slide 6: Architecture
- **Modular Design**: Separation of concerns.
- `src/gui`: All UI components.
- `src/models`: Database and business logic.
- `src/utils`: Helper functions.

## Slide 7: Key Features
- Secure Login & Registration.
- Full CRUD operations on Expenses.
- Dynamic Categories.
- Monthly Budget tracking.

## Slide 8: Key Features (Cont'd)
- Dark/Light Theme Support.
- CSV Exporting.
- Visual Analytics (Pie & Bar charts).

## Slide 9: Database Schema
- **users**: Stores authentication details.
- **categories**: Links to user.
- **expenses**: Links to user and category.
- **budgets**: Monthly limits.

## Slide 10: Testing
- Used Python's `unittest` framework.
- Automated tests for database operations and models.
- Ensures data integrity and validation rules.

## Slide 11: GitHub & Agile
- Agile methodology: Iterative development.

## Slide 12: Challenges Faced
- Managing Tkinter's event loop with matplotlib.
- Ensuring dynamic UI updates.
- Refactoring legacy code into OOP structures.

## Slide 13: Learning Outcomes
- Advanced OOP in Python.
- Database relationship management.
- Desktop application packaging (PyInstaller).

## Slide 14: Conclusion
